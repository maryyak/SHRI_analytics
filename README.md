# SHRI Analytics — Автотесты

## ✅ Описание тестовых сценариев

### 🧪 Unit & Component Tests (Vitest + React Testing Library)

Файлы находятся в `src/tests/unit/` и `src/tests/integration/`.

| Компонент        | Что проверяется                                              |
|------------------|--------------------------------------------------------------|
| `CSVGenerator`   | Отображение загрузки, ошибки, вызов API                      |
| `CSVAnalyst`     | Отправка CSV, парсинг chunked-ответов, ошибки                |
| `historyStore`   | Чтение/запись в localStorage, очистка и удаление записей     |
| `AppWrapper`     | Навигация между страницами, активные ссылки                  |

---

### 🧪 End-to-End (Playwright)

Файл: `src/tests/e2e/full-flow.spec.ts`

Проверяется **полный путь пользователя**:
1. Генерация CSV-файла и его скачивание.
2. Загрузка сгенерированного файла на страницу анализа.
3. Завершение анализа с отображением результата.
4. Появление загруженного файла в Истории.

---

## ⚙️ Используемые технологии

| Инструмент            | Назначение                         |
|-----------------------|------------------------------------|
| **Vitest**            | Юнит и интеграционные тесты       |
| **React Testing Library** | Тестирование компонентов UI     |
| **Playwright**        | E2E-тестирование с браузерной симуляцией |
| **Jest-DOM**          | Расширения для удобных assert'ов  |

## 🚀 Как запустить

### 📦 Установка зависимостей

```bash
npm install
```
✅ Запуск unit / integration тестов (Vitest)
```bash
npm run test
```

🧪 Запуск E2E (Playwright)
1. Запуск клиента
```bash
npm run dev
```
2. Запуск сервера
```bash
cd server
npm install
npm start
```
3. В отдельном терминале — Playwright
```bash
npx playwright test
```
⚠️ Важно: тесты используют baseURL: http://localhost:5173. Убедитесь, что приложение работает на этом порте, или настройте baseURL в playwright.config.ts.
